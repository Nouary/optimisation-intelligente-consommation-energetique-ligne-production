# energy_ml_project

Project scaffold for the Steel Line Energy dataset.

Structure:

- data/steel_line_energy_dataset.csv — dataset (moved here)
- 01_eda.py — exploratory data analysis starter
- 02_preprocessing.py — data loading and train/test split
- 03_modeling.py — training and saving a baseline model

Quick start:

```powershell
python energy_ml_project\01_eda.py
python energy_ml_project\02_preprocessing.py
python energy_ml_project\03_modeling.py
```

Update `02_preprocessing.py` to select the correct target column before training.
